# SZPI-OS 产品需求文档

## 1. 产品概述

SZPI-OS 是运行在立创·实战派 ESP32-S3 开发板上的嵌入式操作系统固件。

## 2. 目标硬件平台

- 模组：ESP32-S3-WROOM-1-N16R8（双核 240MHz / 512KB SRAM / 8MB PSRAM / 16MB Flash）
- 显示屏：ST7789，2.0 寸 IPS，320×240，SPI 接口
- 触摸：FT6336，I2C 接口
- IMU：QMI8658，I2C 接口
- 音频：ES8311 DAC + ES7210 ADC + NS4150B 功放 + 双麦克风 + 1W 喇叭
- 摄像头：GC0308，DVP 接口
- 存储：TF 卡（SDMMC 1-SD）+ 16MB Flash
- 通信：Wi-Fi 802.11 b/g/n（2.4GHz）+ Bluetooth 5 LE + Mesh
- 按键：1 个用户键（BOOT，GPIO0）+ 1 个复位键（EN）
- 电源：Type-C USB

## 3. 功能需求

### 3.1 系统与内核

#### SYS-001 启动序列

- 输入：上电 / 复位信号
- 输出：完整启动流程（驱动初始化 → 内核服务 → UI 框架 → 应用注册 → 显示启动画面 → 进入桌面）
- 行为：按预定顺序初始化各层
- 边界：启动过程失败 → 自动重启并记录错误日志
- 优先级：P0
- 依赖：无
- 验收标准：
  - 上电后 3 秒内显示桌面
  - 启动失败有日志记录

#### SYS-002 多任务调度

- 输入：FreeRTOS 内核
- 输出：多任务并行执行
- 行为：基于 FreeRTOS 的多任务调度
- 优先级：P0
- 依赖：ESP-IDF FreeRTOS
- 验收标准：CPU 占用率可通过日志统计输出

#### SYS-003 双核管理

- 输入：双核 CPU（ESP32-S3）
- 输出：核心 0 / 核心 1 任务分配
- 优先级：P1
- 依赖：SYS-002
- 验收标准：音频解码任务在核心 1 运行，不影响 UI 主任务

#### SYS-004 看门狗

- 输入：系统异常 / 任务挂起
- 输出：自动重启系统
- 行为：启用 Task Watchdog，监控关键任务，超时自动重启
- 边界：喂狗超时阈值（默认 5 秒可配）
- 优先级：P0
- 依赖：SYS-002
- 验收标准：关键任务挂起超过阈值后系统自动重启

#### SYS-005 异常处理与 crash log

- 输入：系统异常 / 断言失败
- 输出：崩溃日志保存到 NVS，下次启动可读取
- 行为：
  - 启用 espcoredump
  - 崩溃时记录寄存器状态、调用栈
  - 崩溃日志写入 NVS
- 边界：NVS 容量有限，仅保留最近若干次崩溃
- 优先级：P1
- 依赖：SYS-002
- 验收标准：触发崩溃后重启，串口可读到 crash 信息

#### SYS-006 系统信息查询

- 输入：API 调用
- 输出：内存使用 / Flash 使用 / CPU 占用率 / 任务状态
- 行为：提供统一 API 返回运行时信息
- 边界：API 内部加锁保护，并发安全
- 优先级：P1
- 依赖：SYS-002
- 验收标准：API 返回值与实际硬件状态一致

#### SYS-007 时间管理

- 输入：NTP 同步 / 手动设置
- 输出：本地时间（年/月/日/时/分/秒/时区）
- 行为：
  - 维护系统时间戳
  - 支持时区设置
  - SNTP 自动同步
- 优先级：P0
- 依赖：通信 - SNTP 同步
- 验收标准：联网后时间自动同步；手动设置后时钟 App 显示正确

#### SYS-008 软复位 / 硬复位

- 输入：API 调用 / 复位键（EN）
- 输出：系统重新启动
- 行为：
  - 软复位：调用系统复位接口，保留 NVS 数据
  - 硬复位：复位键（EN）触发，复位芯片
- 边界：硬复位会丢失运行时内存数据
- 优先级：P0
- 依赖：SYS-002
- 验收标准：调用软复位 API 后系统重启；按复位键触发硬复位

#### SYS-009 电源管理

- 输入：超时无操作 / 用户请求
- 输出：屏幕熄灭 / 深度睡眠 / 唤醒
- 行为：
  - 屏幕超时自动熄灭（可配 N 秒）
  - 触摸 / 按键 / IMU 唤醒
  - 提供深度睡眠 API（预留）
- 边界：睡眠期间 Wi-Fi/BLE 断开，恢复需重新连接
- 优先级：P1
- 依赖：SYS-002、SYS-007
- 验收标准：超时后屏幕熄灭；触摸唤醒屏幕

#### SYS-010 OTA 在线升级

- 输入：固件 URL / 本地 .bin 文件
- 输出：固件下载、写入 OTA 分区、重启进入新固件
- 行为：
  - 从 HTTPS 服务器下载固件（强制 TLS，禁止明文 HTTP）
  - 写入 ota_0 / ota_1 分区
  - 重启切换固件
  - 失败回滚
- 边界：固件大小受 OTA 分区限制（4MB）
- 优先级：P1
- 依赖：通信 - HTTPS 支持、SYS-008
- 验收标准：成功升级后系统运行新固件；升级失败回滚到原固件

### 3.2 UI 系统

#### UI-001 主题系统

- 输入：用户设置 / 系统默认
- 输出：深色 / 浅色主题切换
- 行为：
  - 全局颜色变量定义
  - LVGL 主题对象构建
  - 应用层根据主题变量渲染
- 边界：仅深色 / 浅色二选一
- 优先级：P0（深色默认）
- 依赖：无
- 验收标准：
  - 默认启动深色主题
  - 切换主题后所有屏幕立即刷新

#### UI-002 主题运行时切换

- 输入：UI-001 主题状态变化
- 输出：当前主题改变 + 所有屏幕重新渲染
- 行为：发布主题变化事件，所有应用订阅
- 边界：切换瞬间可能短暂闪屏
- 优先级：P1
- 依赖：UI-001、事件总线
- 验收标准：设置中切换后立即生效，无需重启

#### UI-003 字体系统

- 输入：字体名称 / 字号
- 输出：渲染对应字体文字
- 行为：
  - 内置多种字号英文字体
  - 中文字体（开源字库）
  - 按需加载到 PSRAM
- 边界：字体占用 PSRAM，需按需释放
- 优先级：P0
- 依赖：无
- 验收标准：所有界面文字渲染正确，无缺字

#### UI-004 图片资源系统

- 输入：图片路径 / 资源 ID
- 输出：图片渲染到屏幕
- 行为：
  - 内置图片编译进固件
  - TF 卡图片运行时读取
  - 缓存机制避免重复加载
- 边界：图片格式支持 PNG / GIF / BMP（JPEG 由相机软件编码产生）
- 优先级：P0
- 依赖：存储 - TF 卡
- 验收标准：内置图片与 TF 卡图片均能正确显示

#### UI-005 图标系统

- 输入：图标 ID
- 输出：图标渲染
- 行为：内置图标数组，每个 App 一个图标
- 边界：图标尺寸固定
- 优先级：P0
- 依赖：UI-004（图片资源）
- 验收标准：桌面图标清晰显示，无锯齿

#### UI-006 通用 UI 组件

- 输入：组件类型 + 参数
- 输出：进度条 / 对话框 / Toast 等
- 行为：基于 LVGL 封装统一 API
- 边界：自定义样式可能不兼容
- 优先级：P0
- 依赖：UI-001、UI-003
- 验收标准：组件在所有应用中风格一致

#### UI-007 状态栏

- 输入：时间 / Wi-Fi / 蓝牙状态
- 输出：屏幕顶部状态栏显示
- 行为：
  - 显示时间（实时更新）
  - 显示 Wi-Fi 图标（连接状态）
  - 显示蓝牙图标（开关状态）
- 边界：状态栏占据顶部 24px
- 优先级：P0
- 依赖：UI-001、SYS-007（时间）、通信 - Wi-Fi
- 验收标准：
  - 桌面显示完整状态栏
  - Wi-Fi 连接变化时图标实时更新

#### UI-008 应用列表

- 输入：注册的应用
- 输出：网格布局的应用图标
- 行为：
  - 4×2 或 3×3 网格
  - 显示应用名称
  - 点击启动应用
- 边界：内置 App 17 个，网格分页显示
- 优先级：P0
- 依赖：应用框架、UI-005
- 验收标准：
  - 显示所有注册的应用
  - 点击图标启动对应 App

#### UI-009 应用切换

- 输入：HOME 键 / 应用列表 / 返回手势
- 输出：当前应用切换
- 行为：
  - 当前应用压栈
  - 新应用入栈
  - HOME 键 → 回到桌面
  - 返回键 → 弹出栈顶
- 边界：栈深度受内存限制
- 优先级：P0
- 依赖：应用框架
- 验收标准：
  - HOME 键直接回桌面
  - 返回键能逐级退出

#### UI-010 桌面

- 输入：HOME 键 / 系统启动
- 输出：桌面应用（图标网格 + 状态栏 + 虚拟按键栏）
- 行为：
  - 显示状态栏
  - 显示应用网格
  - 显示虚拟按键栏
- 边界：桌面是默认顶层应用
- 优先级：P0
- 依赖：UI-007、UI-008、UI-011（虚拟按键栏）
- 验收标准：上电后桌面正常显示

#### UI-011 虚拟按键栏

- 输入：触摸事件
- 输出：模拟 BACK / HOME 按键
- 行为：
  - 屏幕底部显示两个按钮
  - BACK 触发应用返回
  - HOME 触发回桌面
- 边界：占用底部 24-32px
- 优先级：P0
- 依赖：UI-009
- 验收标准：触摸虚拟按键效果等同物理按键

#### UI-012 过渡动画

- 输入：应用切换事件
- 输出：淡入淡出 / 滑动动画
- 行为：应用切换时 200-300 ms 过渡动画
- 边界：动画期间禁止触摸
- 优先级：P1
- 依赖：应用框架
- 验收标准：切换应用有视觉过渡，无瞬变

#### UI-013 音量调节

- 输入：UI 滑块 / 物理按键（预留）
- 输出：音量 0-100% 调节
- 行为：
  - 屏幕弹出音量条
  - 实时调节音频 codec 音量
- 优先级：P0
- 依赖：MM-003
- 验收标准：滑块调节实时生效，音频音量变化

#### UI-014 屏幕亮度调节

- 输入：UI 滑块 / 控制中心
- 输出：LCD 背光 0-100% 调节
- 行为：
  - 调节背光亮度
  - 设置持久化到 NVS
- 边界：亮度 0 表示关闭背光
- 优先级：P0
- 依赖：硬件规格
- 验收标准：
  - 滑块调节实时生效
  - 重启后保持上次亮度

#### UI-015 屏幕超时熄屏

- 输入：无操作时间累计
- 输出：屏幕熄灭（背光关闭，LCD 保持）
- 行为：
  - 默认 30 秒无操作自动熄屏
  - 触摸 / 按键 / IMU 唤醒
  - 超时时间可配置
- 边界：熄屏 ≠ 关机
- 优先级：P1
- 依赖：SYS-009（电源管理）
- 验收标准：超时后屏幕熄灭；触摸后屏幕亮起

#### UI-016 屏幕唤醒

- 输入：触摸 / 按键 / IMU 事件
- 输出：屏幕点亮
- 行为：从熄屏状态恢复到正常显示
- 边界：唤醒后立即响应触摸
- 优先级：P1
- 依赖：UI-015
- 验收标准：熄屏后任意输入立即点亮屏幕

#### UI-017 屏幕旋转

- 输入：用户设置 / IMU 检测方向
- 输出：屏幕内容旋转 0° / 90° / 180° / 270°
- 行为：
  - LVGL display rotation 配置
  - 触摸坐标同步旋转
- 边界：旋转后图标方向不变（仅内容旋转）
- 优先级：P2
- 依赖：UI-008、UI-009
- 验收标准：旋转后触摸方向仍然正确

#### UI-018 多语言支持（i18n）

- 输入：用户语言设置
- 输出：界面文字按所选语言显示
- 行为：
  - 字符串资源按语言分类
  - 当前语言切换立即刷新
- 边界：第一版仅支持中文 + 英文
- 优先级：P2
- 依赖：UI-003
- 验收标准：切换语言后所有界面立即刷新

### 3.3 输入系统

#### IN-001 触摸输入

- 输入：FT6336 触摸事件
- 输出：触摸坐标 + 按下 / 抬起事件
- 行为：
  - 轮询扫描触摸点（INT 引脚未用）
  - 单点坐标解析
  - 传递到 LVGL input device
- 边界：单点触摸（FT6336），不支持多指手势
- 优先级：P0
- 依赖：硬件规格
- 验收标准：触摸屏幕任意点能准确定位

#### IN-002 物理按键输入

- 输入：BOOT 键 GPIO0 下降沿
- 输出：按键事件（单击 / 双击 / 长按）
- 行为：
  - GPIO 中断触发
  - 计时器判断多击 / 长按
  - 传递到应用框架
- 边界：仅 1 个用户按键（BOOT）
- 优先级：P0
- 依赖：硬件规格
- 验收标准：
  - 单击 / 双击 / 长按准确识别
  - 不超过 100 ms 响应延迟

#### IN-003 手势识别

- 输入：触摸轨迹
- 输出：滑动方向（上下左右）
- 行为：
  - 触摸起止坐标对比
  - 阈值判断（默认 50px）
  - 单指滑动支持
- 边界：滑动必须超出阈值才识别
- 优先级：P1
- 依赖：IN-001
- 验收标准：四方向滑动准确识别，无误触

#### IN-004 IMU 姿态输入

- 输入：QMI8658 加速度 / 陀螺仪数据
- 输出：姿态变化事件（横竖屏 / 抬起 / 摇晃 / 敲击）
- 行为：
  - 后台任务持续读取 IMU
  - 50Hz 采样
  - 检测阈值变化触发事件
- 边界：IMU 必须初始化后才能输入
- 优先级：P1
- 依赖：硬件规格
- 验收标准：晃动板子能触发摇一摇事件

#### IN-005 多击识别

- 输入：连续按键 / 触摸事件
- 输出：单击 / 双击 / 三击事件
- 行为：基于时间窗口（默认 500 ms 内）的多击计数
- 边界：超出时间窗口重置计数
- 优先级：P1
- 依赖：IN-002 / IN-001
- 验收标准：单击 / 双击 / 三击准确区分

#### IN-006 长按识别

- 输入：按键 / 触摸持续按住
- 输出：长按事件（持续 N 秒触发）
- 行为：默认 1.5 秒触发
- 边界：与单击互斥（不能同时触发）
- 优先级：P1
- 依赖：IN-002 / IN-001
- 验收标准：长按 1.5 秒后正确触发

#### IN-007 按键映射配置

- 输入：用户设置
- 输出：按键行为映射（如单击 = 返回）
- 行为：
  - 配置文件存储按键映射
  - 启动时加载
- 边界：第一版仅支持默认映射
- 优先级：P2
- 依赖：IN-002
- 验收标准：用户配置后按键按新映射响应

#### IN-008 输入防抖

- 输入：触摸 / 按键事件流
- 输出：去抖动后的事件
- 行为：
  - 软件防抖（50 ms 时间窗）
  - 抖动期内忽略后续事件
- 边界：可能漏掉快速连击（极端情况）
- 优先级：P2
- 依赖：IN-001 / IN-002
- 验收标准：连续抖动只触发一次事件

### 3.4 通知系统

#### NOTI-001 通知发送

- 输入：App 调用 API + 通知内容
- 输出：通知进入队列，触发显示与存储
- 行为：
  - 应用调用统一 API
  - 分配唯一 ID
  - 加入队列
- 边界：通知携带数据大小有限（指针 + 长度）
- 优先级：P0
- 依赖：无
- 验收标准：API 调用后通知立即出现在队列中

#### NOTI-002 通知接收

- 输入：底层服务事件（Wi-Fi 连接 / 存储变化等）
- 输出：自动生成通知
- 行为：各服务主动 post 通知
- 边界：第一版仅核心服务支持
- 优先级：P1
- 依赖：NOTI-001、各服务
- 验收标准：Wi-Fi 连接后弹出通知

#### NOTI-003 通知中心

- 输入：通知队列
- 输出：用户可下拉查看历史通知
- 行为：
  - 屏幕中部弹出面板
  - 列表显示通知
  - 点击跳转到对应 App
- 边界：通知中心是覆盖层，不阻塞其他 UI
- 优先级：P0
- 依赖：NOTI-001、UI-006
- 验收标准：
  - 下拉手势显示通知中心
  - 点击通知能跳转

#### NOTI-004 通知分类

- 输入：通知 type 字段
- 输出：通知按类型图标 / 颜色区分
- 行为：信息 / 警告 / 错误 / 成功 / 进度 5 类
- 边界：分类影响显示样式
- 优先级：P1
- 依赖：NOTI-001
- 验收标准：不同类型通知图标不同

#### NOTI-005 通知持久化

- 输入：通知生成
- 输出：通知保存到 NVS / SPIFFS
- 行为：
  - 通知写入存储
  - 重启后恢复未读通知
- 边界：NVS 容量限制，仅保留最近 50 条
- 优先级：P1

### 3.6 通信

- 优先级：P2
- 依赖：NET-002
- 验收标准：能连接 broker 并收发消息

#### NET-014 WebSocket 客户端

## 4. 非功能需求

### 4.1 性能

- 启动时间：上电到桌面 < 3 秒
- UI 帧率：动画 / 滑动 ≥ 30 FPS
- 触摸响应延迟：< 100 ms
- Wi-Fi 连接时间（已知 SSID）：< 5 秒
- 音乐启动延迟：< 300 ms
- 应用切换时间：< 500 ms

### 4.2 可靠性

- 连续运行（不重启）：≥ 72 小时
- 看门狗：关键任务全部纳入监控
- OTA 失败回滚：自动回滚到上一版本
- 崩溃日志：保留最近若干次崩溃信息

### 4.3 兼容性

- 硬件：立创·实战派 ESP32-S3 (N16R8)
- 工具链：ESP-IDF v5.4.4
- 编译器：GCC (xtensa-esp32s3-elf-gcc)
- 文件系统：FAT32 (TF 卡) + SPIFFS (内置 Flash)

### 4.4 可维护性

- 代码组织：5 层分层（Drivers / Peripherals / Services / Framework / Apps）
- 头文件：每个公共 API 有 Doxygen 注释
- 编码风格：遵循 ESP-IDF 编码规范
- 配置项：关键参数可在 menuconfig 中调整
