# SZPI-OS 产品需求文档

## 1. 产品概述

SZPI-OS 是运行在立创·实战派 ESP32-S3 开发板上的嵌入式操作系统固件。

## 2. 功能需求

### 2.1 系统与内核

#### SYS-001 启动序列

- 输入：上电 / 复位信号
- 输出：完整启动流程（驱动初始化 → 外设初始化 → 服务初始化 → 框架初始化 → 注册 App → 开机画面 → 进入桌面）
- 行为：按预定顺序初始化各层；内置 Flash 在首屏之后挂载，看门狗在启动完成后才打开超时自动重启
- 边界：关键层初始化失败则中止启动并记录日志
- 优先级：P0
- 依赖：无
- 验收标准：
  - 上电后 5 秒内显示桌面
  - 启动失败有日志记录

#### SYS-002 多任务调度

- 输入：FreeRTOS 内核
- 输出：多任务并行执行
- 行为：基于 FreeRTOS 的任务调度，每个服务独占任务
- 优先级：P0
- 依赖：ESP-IDF FreeRTOS
- 验收标准：任务 CPU 占用可查询

#### SYS-003 看门狗

- 输入：系统异常 / 任务挂起
- 输出：超时自动重启系统
- 行为：Task Watchdog 监控关键任务；启动完成前只告警，启动完成后打开自动重启
- 边界：超时阈值默认 5 秒，可配
- 优先级：P0
- 依赖：SYS-002
- 验收标准：关键任务挂起超过阈值后系统自动重启

#### SYS-004 异常处理与 crash log

- 输入：系统异常 / 断言失败
- 输出：崩溃现场写入保留内存，重启后写入 NVS 并打印
- 行为：包装 panic handler，记录任务名 / 调用栈 / 运行时长；只保留最近若干条
- 边界：无 coredump 分区；cache 关闭时崩溃只保留复位原因
- 优先级：P1
- 依赖：SYS-002
- 验收标准：触发崩溃重启后，串口可读到崩溃信息

#### SYS-005 系统信息查询

- 输入：API 调用
- 输出：CPU / 内存 / Flash 使用情况、复位原因、运行时长
- 行为：统一 API 返回运行时信息
- 边界：API 内部加锁，并发安全
- 优先级：P1
- 依赖：SYS-002
- 验收标准：返回值与实际状态一致

#### SYS-006 软复位 / 硬复位

- 输入：API 调用 / 复位键（EN）
- 输出：系统重新启动
- 行为：软复位保留 NVS 数据；硬复位由 EN 键触发
- 边界：复位丢失运行时内存数据
- 优先级：P0
- 依赖：无
- 验收标准：调用软复位 API 后系统重启；按 EN 键触发硬复位

#### SYS-007 电源管理（关机 / 重启）

- 输入：用户请求
- 输出：关机 / 重启
- 行为：提供关机与重启接口；重启走软复位
- 边界：关机不切断 Type-C 供电
- 优先级：P0
- 依赖：SYS-006
- 验收标准：关机 / 重启入口生效

#### SYS-008 时间管理

- 输入：SNTP 同步 / 手动设置
- 输出：本地时间（年 / 月 / 日 / 时 / 分 / 秒 / 时区）
- 行为：维护系统时间戳；支持时区设置与 12 / 24 小时制；联网后自动同步，并每 6 小时定时重新同步；未联网时可手动校时（精确到秒）
- 边界：12 / 24 小时制存在 NVS（`sys/clock_24h`），状态栏与时钟 App 共用同一个设置；本板无电池 RTC，热重启（软件复位 / panic / 看门狗）后时间从 RTC 保留内存接着走，掉电则需重新校时或联网同步
- 优先级：P0
- 依赖：无
- 验收标准：联网后时间自动同步；设置后时钟 App 与状态栏显示一致且正确；热重启后时间仍然可信、不回到"未同步"

#### SYS-009 屏幕超时熄屏 / 唤醒

- 输入：无操作时间累计 / 触摸 / 按键 / 抬手
- 输出：屏幕熄灭 / 点亮
- 行为：默认 30 秒无操作熄屏（只关背光，LCD 保持）；触摸 / 按键 / 抬手唤醒
- 边界：熄屏 ≠ 关机
- 优先级：P1
- 依赖：SYS-007
- 验收标准：超时后熄屏；触摸 / 按键 / 抬手点亮

#### SYS-010 亮度调节

- 输入：UI 滑块 / 控制接口
- 输出：LCD 背光 0-100%
- 行为：调节背光亮度并持久化到 NVS
- 边界：亮度 0 表示关闭背光
- 优先级：P0
- 依赖：无
- 验收标准：调节实时生效，重启后保持

#### SYS-011 音量调节

- 输入：UI 滑块 / 控制接口
- 输出：音频输出音量 0-100%
- 行为：实时调节 codec 音量并持久化
- 优先级：P0
- 依赖：无
- 验收标准：调节实时生效

### 2.2 脚本系统

#### SCR-001 脚本运行时

- 输入：Lua 脚本
- 输出：脚本执行
- 行为：内置 Lua 5.5 运行时，提供加载、执行、停止接口
- 边界：运行内存受内部 RAM / PSRAM 限制
- 优先级：P0
- 依赖：无
- 验收标准：能加载并执行示例脚本

#### SCR-002 脚本列表与元信息

- 输入：脚本目录
- 输出：脚本列表（名称 / 说明 / 入口）
- 行为：扫描脚本目录，读取每个脚本的元信息，供脚本管理展示
- 边界：无元信息的脚本以文件名作为名称
- 优先级：P0
- 依赖：STO-001
- 验收标准：脚本管理列出目录下所有脚本

#### SCR-003 脚本生命周期管理

- 输入：运行 / 停止请求
- 输出：脚本启动 / 停止 / 异常退出
- 行为：同一时刻只运行一个前台脚本；脚本退出或异常时释放资源并回到脚本管理
- 边界：脚本异常退出不影响系统
- 优先级：P0
- 依赖：SCR-001
- 验收标准：运行中可停止；异常退出后系统正常

#### SCR-004 脚本错误处理与日志

- 输入：脚本语法 / 运行错误
- 输出：错误信息（行号 + 描述）
- 行为：捕获 Lua 错误，写日志并在界面提示
- 优先级：P1
- 依赖：SCR-001
- 验收标准：错误脚本给出明确报错，不崩溃

#### SCR-005 脚本配置持久化

- 输入：脚本读写配置
- 输出：配置保存到 NVS 或文件
- 行为：脚本通过 API 持久化自己的配置
- 优先级：P1
- 依赖：SCR-001、STO-007
- 验收标准：脚本配置跨重启保留

#### SCR-006 脚本权限与沙箱

- 输入：脚本头部的能力声明
- 输出：脚本内可用的能力模块
- 行为：脚本头部用 `-- @perm io,file,net` 声明要用的能力模块；不写声明表示全部模块可用；写了声明就只注册列出的模块，未声明的模块在脚本里为 nil，调用即报 Lua 错
- 边界：ESP32-S3 无 MMU，为软件级限制
- 优先级：P2
- 依赖：SCR-001
- 验收标准：脚本声明限制后，调用未声明的模块报 Lua 错

#### SCR-007 内置示例脚本

- 输入：固件内置脚本
- 输出：首次启动释放到脚本目录
- 行为：随固件打包若干示例脚本，供用户选择运行
- 边界：同名脚本已存在时不覆盖
- 优先级：P1
- 依赖：STO-001
- 验收标准：首次启动后脚本目录有示例脚本

#### SCR-008 网络脚本下载

- 输入：脚本 URL
- 输出：脚本保存到脚本目录
- 行为：通过 HTTP / HTTPS 下载脚本
- 边界：下载失败不残留半截文件
- 优先级：P1
- 依赖：NET-005、STO-001
- 验收标准：输入链接后脚本出现在列表中并可运行

### 2.3 脚本能力

#### CAP-001 显示与界面

- 输入：脚本调用界面接口
- 输出：LVGL 控件 / 页面 / 图片
- 行为：脚本可创建页面与控件，显示文字 / 图片 / 进度 / Toast
- 边界：界面操作在 LVGL 任务上下文执行
- 优先级：P0
- 依赖：SCR-001、UI-006
- 验收标准：脚本能绘制并刷新界面

#### CAP-002 输入

- 输入：触摸 / 姿态 / 按键
- 输出：脚本回调
- 行为：脚本可注册触摸、姿态、按键事件
- 优先级：P0
- 依赖：SCR-001、IN-001 / IN-002 / IN-003
- 验收标准：点击屏幕脚本收到事件

#### CAP-003 音频播放 / 录音

- 输入：脚本调用音频接口
- 输出：播放 / 录音
- 行为：脚本可播放音频文件与提示音、启动 / 停止录音
- 优先级：P1
- 依赖：SCR-001、MM-001 / MM-002
- 验收标准：脚本能播放音频

#### CAP-004 摄像头拍照

- 输入：脚本调用摄像头接口
- 输出：拍照文件
- 行为：脚本可开关摄像头并拍照，照片保存到 TF 卡
- 优先级：P1
- 依赖：SCR-001、MM-004
- 验收标准：脚本能拍照并在 TF 卡生成照片文件

#### CAP-005 GPIO / PWM / I2C / UART / ADC

- 输入：脚本调用硬件接口
- 输出：外设操作
- 行为：脚本可控制 GPIO、输出 PWM、收发 I2C / UART、读取 ADC
- 边界：仅限外扩接口引出的 GPIO10 / GPIO11 与可用外设
- 优先级：P1
- 依赖：SCR-001
- 验收标准：脚本能点亮外接 LED、读写外接 I2C 器件

#### CAP-006 文件读写

- 输入：脚本调用文件接口
- 输出：TF 卡 / 内置 Flash 读写
- 行为：脚本可读写、删除、列目录
- 优先级：P0
- 依赖：SCR-001、STO-003
- 验收标准：脚本能保存并读回文件

#### CAP-007 网络

- 输入：脚本调用网络接口
- 输出：HTTP / HTTPS / MQTT / WebSocket
- 行为：脚本可发 HTTP(S) 请求、连接 MQTT / WebSocket
- 优先级：P1
- 依赖：SCR-001、NET-005 ~ NET-008
- 验收标准：脚本能获取网页内容

#### CAP-008 蓝牙 BLE

- 输入：脚本调用 BLE 接口
- 输出：广播状态 / 连接状态 / 通知
- 行为：脚本可开关广播、扫描周边设备、查询连接状态，并作为 GATT 从机响应中心设备的特征读写、发送通知；不主动连接中心设备，不做 GATT 客户端读写
- 优先级：P1
- 依赖：SCR-001、NET-002
- 验收标准：脚本能开关广播、发送通知；手机能搜索并连接板子

#### CAP-009 时间与系统信息

- 输入：脚本调用
- 输出：时间、内存、运行时长等
- 行为：脚本可读取系统时间、内存与运行时长
- 优先级：P0
- 依赖：SCR-001、SYS-005 / SYS-008
- 验收标准：脚本能读到正确时间与内存

#### CAP-010 事件订阅与发布

- 输入：脚本订阅 / 发布事件
- 输出：事件回调
- 行为：脚本可订阅系统事件，也可发布自定义事件
- 优先级：P0
- 依赖：SCR-001
- 验收标准：脚本收到系统事件回调

#### CAP-011 系统通知（Toast）

- 输入：脚本调用通知接口
- 输出：界面 Toast
- 行为：脚本可弹出 Toast 提示
- 优先级：P1
- 依赖：SCR-001、UI-006
- 验收标准：脚本能弹出 Toast

### 2.4 UI 系统

#### UI-001 主题系统

- 输入：用户设置 / 系统默认
- 输出：深色 / 浅色主题
- 行为：调色板统一走主题接口，控件显式设色
- 边界：仅深色 / 浅色二选一
- 优先级：P0
- 依赖：无
- 验收标准：默认深色；两种主题下控件均可见

#### UI-002 主题运行时切换

- 输入：用户切换主题
- 输出：全局立即刷新
- 行为：切换后重建状态栏、浮层与所有界面
- 优先级：P1
- 依赖：UI-001
- 验收标准：切换后立即生效，无需重启

#### UI-003 字体系统

- 输入：字体名称 / 字号
- 输出：渲染对应字体文字
- 行为：中文字体为内置子集，拉丁 / 数字用内置 Montserrat
- 边界：界面文案的汉字必须在字体子集内
- 优先级：P0
- 依赖：无
- 验收标准：所有界面文字渲染正确，无缺字

#### UI-004 图片资源系统

- 输入：图片路径
- 输出：图片渲染到屏幕
- 行为：内置图片编译进固件，TF 卡图片运行时读取
- 边界：支持 PNG / JPEG / GIF / BMP
- 优先级：P0
- 依赖：STO-001
- 验收标准：内置与 TF 卡图片均能正确显示

#### UI-005 图标系统

- 输入：图标标识
- 输出：图标渲染
- 行为：每个 App 一个图标，优先用内置符号
- 边界：图标尺寸固定
- 优先级：P0
- 依赖：UI-004
- 验收标准：桌面图标清晰显示

#### UI-006 通用 UI 组件

- 输入：组件类型 + 参数
- 输出：进度条 / 对话框 / Toast / 列表 / 网格
- 行为：基于 LVGL 封装统一接口
- 优先级：P0
- 依赖：UI-001、UI-003
- 验收标准：组件在所有界面风格一致

#### UI-007 状态栏

- 输入：时间 / Wi-Fi / 蓝牙 BLE / 声音 / 录音 / 摄像头 / TF 卡状态
- 输出：屏幕顶部状态栏
- 行为：左侧为返回与主页按钮；右侧 6 个状态图标全部常显、不可点击，启用 / 触发时用主色高亮，否则置灰
  - Wi-Fi：连上 AP 时高亮（未连接 / 连接中 / 失败都置灰）
  - 蓝牙 BLE：广播中或已连接时高亮（关闭广播且未连接则置灰）
  - 声音：扬声器放音时高亮
  - 录音：麦克风录音时高亮
  - 摄像头：摄像头打开时高亮
  - TF 卡：卡可用（已挂载且仍能访问）时高亮
- 边界：状态栏高度固定；图标亮灭由各服务事件驱动实时响应，另有 1 s 兜底同步
- 优先级：P0
- 依赖：UI-001、SYS-008、NET-001
- 验收标准：各图标严格跟随上表对应状态的亮灭，不出现残留高亮

#### UI-008 桌面

- 输入：系统启动 / 主页键
- 输出：应用图标网格 + 状态栏
- 行为：一屏固定 4×2，超出可翻页；每个格子为彩色图标 + 中文名称，点击图标启动 App
- 边界：桌面是返回栈的栈底
- 优先级：P0
- 依赖：UI-005、UI-007
- 验收标准：上电后桌面正常显示，图标可点击

### 2.5 输入系统

#### IN-001 触摸输入

- 输入：FT6336 触摸事件
- 输出：触摸坐标与点击 / 长按事件
- 行为：扫描任务轮询读取坐标并缓存，LVGL 输入设备只读缓存
- 边界：单点触摸，不支持多指手势
- 优先级：P0
- 依赖：无
- 验收标准：点击 / 长按定位准确

#### IN-002 IMU 姿态输入

- 输入：QMI8658 加速度 / 陀螺仪数据
- 输出：姿态变化 / 摇晃 / 抬手事件
- 行为：后台任务周期采样，按阈值触发事件
- 边界：IMU 初始化失败则不产生事件
- 优先级：P1
- 依赖：SNS-001
- 验收标准：晃动板子能触发摇晃事件

#### IN-003 物理按键输入

- 输入：BOOT 键 GPIO0
- 输出：单击 / 双击 / 长按事件
- 行为：轮询 + 软件去抖判定；单击返回上一级、双击回到桌面、长按弹出电源菜单（按住期间到点即弹出，不需松手）
- 边界：仅 1 个用户按键
- 优先级：P0
- 依赖：无
- 验收标准：单击 / 双击 / 长按准确识别

#### IN-004 输入防抖

- 输入：触摸 / 按键事件流
- 输出：去抖后的事件
- 行为：软件防抖（50 ms 时间窗）
- 边界：可能漏掉极快的连击
- 优先级：P1
- 依赖：IN-001 / IN-003
- 验收标准：连续抖动只触发一次事件

### 2.6 多媒体

#### MM-001 音频播放（MP3）

- 输入：MP3 文件路径 / HTTP(S) 链接 / 外部 PCM 流
- 输出：通过喇叭播放
- 行为：解码 MP3 并写入 I2S；支持从 HTTP(S) 链接播放；支持接收外部 PCM 流直接写 I2S
- 边界：URL 播放需联网；外部流由调用方提供 PCM 数据
- 优先级：P0
- 依赖：SYS-011、STO-001
- 验收标准：成功播放 MP3 音质清晰；能播放 HTTP(S) 链接；能播放外部 PCM 流

#### MM-002 录音与播放（WAV）

- 输入：麦克风采集 / WAV 文件
- 输出：WAV 文件 / 播放音频
- 行为：采集 PCM 并写入 WAV 头，支持播放 WAV
- 边界：16-bit，采样率 16 kHz / 44.1 kHz / 48 kHz
- 优先级：P0
- 依赖：STO-001
- 验收标准：录音文件能在 PC 上正常播放

#### MM-003 摄像头预览

- 输入：摄像头数据
- 输出：实时画面到 LCD

### 2.7 通信

#### NET-001 Wi-Fi 配网与管理

- 输入：API 调用 / 用户配网
- 输出：连接 / 断开状态、IP
- 行为：扫描、连接（STA）、自动重连，支持 Web 配网与 SmartConfig，支持忘记网络
- 边界：重试失败后保持断开状态
- 优先级：P0
- 依赖：无
- 验收标准：连接成功后能 ping 通外网

#### NET-002 蓝牙 BLE 连接与管理

- 输入：API 调用
- 输出：广播 / 扫描 / 连接状态
- 行为：BLE 广播与扫描，GATT 从机读写与通知；仅作外设角色，不发起中心设备连接，不做 GATT 客户端读写
- 边界：仅 BLE，不使用经典蓝牙；控制器内存受限
- 优先级：P1
- 依赖：无
- 验收标准：能被手机搜索并连接，并作为 GATT 从机通信

#### NET-003 时间同步（SNTP）

- 输入：联网成功
- 输出：本地时间校准
- 行为：连接 NTP 服务器；联网后立刻同步一次，之后每 6 小时定时重新同步（SNTP 客户端自身也按 IDF 的轮询周期同步）
- 边界：需要联网
- 优先级：P0
- 依赖：NET-001、SYS-008
- 验收标准：联网后时间自动校准；时钟 App 的「立即同步」也能手动触发一次

#### NET-004 时区设置

- 输入：用户选择时区

- 边界：时区以 POSIX TZ 字符串持久化（`sys/timezone`）；列表里的偏移只作显示，实际时差（含夏令时）由 TZ 规则算出
- 优先级：P0
- 依赖：NET-003、SYS-008
- 验收标准：选择北京时区后时间 +8 小时

#### NET-005 HTTP 客户端

- 依赖：NET-001
- 验收标准：能访问外部 HTTP 接口

#### NET-008 WebSocket 客户端

- 验收标准：能与服务器收发文本消息

#### NET-009 蓝牙 HID 设备模拟

## 3. 非功能需求

### 3.1 性能

- 启动时间：上电到桌面 < 5 秒
- UI 帧率：动画 / 滑动 ≥ 30 FPS
- 触摸响应延迟：< 100 ms
- Wi-Fi 连接时间（已知 SSID）：< 5 秒
- 脚本启动延迟：< 500 ms
- 音乐启动延迟：< 300 ms

### 3.2 可靠性

- 连续运行（不重启）：≥ 72 小时
- 看门狗：关键任务全部纳入监控
- 崩溃日志：保留最近若干次
- 脚本异常：不拖垮系统

### 3.3 兼容性

- 硬件：立创·实战派 ESP32-S3（N16R8）
- 工具链：ESP-IDF v6.1
- 编译器：GCC（xtensa-esp32s3-elf-gcc）
- 文件系统：FAT32（TF 卡）+ SPIFFS（内置 Flash）

### 3.4 可维护性

- 代码组织：5 层分层（Drivers / Peripherals / Services / Framework / Apps）
- 头文件：每个公共 API 有中文注释
- 编码风格：遵循项目既有命名与日志约定
- 配置项：关键参数在 sdkconfig.defaults 中调整
